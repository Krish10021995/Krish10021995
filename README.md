### 🤖 End-to-End MLOps Pipeline

A production-shaped ML lifecycle demonstrating:

```text
Data
  ↓
Feature Engineering
  ↓
Model Training
  ↓
Evaluation & Quality Gate
  ↓
MLflow Model Registry
  ↓
FastAPI
  ↓
Docker
  ↓
AWS ECR
  ↓

  ↓
Prometheus + Grafana
  ↓
Drift Detection
```
